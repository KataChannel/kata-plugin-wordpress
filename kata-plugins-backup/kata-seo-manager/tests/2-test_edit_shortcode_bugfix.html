🐛 Edit Shortcode Bug Fix

Fix: Modal không hiện attributes để edit

✅ FIXED

🐛 Bug Mô Tả

⚠️ Vấn Đề

Khi double-click vào shortcode trong editor:

  • ✅ Modal "Editing Existing Schema" mở thành công
  • ✅ Thấy message: "Modify attributes below and click Update to save changes."
  • ❌ NHƯNG không có form attributes nào để edit!
  • ❌ Chỉ thấy container trống, không thể chỉnh sửa gì

📋 Reproduction Steps

  1. Tạo post với shortcode: [kata_article title="Test" author="John"]
  2. Double-click vào shortcode
  3. Modal mở với title "Edit ARTICLE Schema"
  4. Thấy blue info box: "Editing Existing Schema..."
  5. ❌ Không thấy form fields (title, author, etc.)

🔍 Root Cause Analysis

❌ Before (Bug)

// editExistingShortcode() editor.windowManager.open({ ... onopen: function() { renderEditForm(parsed); // ❌ TOO EARLY! } }); // Issue: // - onopen fires before DOM ready // - jQuery('#kata-edit-attributes') returns null // - Form HTML never injected // - User sees empty container

Problem: onopen chạy trước khi container #kata-edit-attributes được render vào DOM.

✅ After (Fixed)

// editExistingShortcode() editor.windowManager.open({ ... onpostrender: function() { setTimeout(function() { renderEditForm(parsed); // ✅ AFTER DOM READY! }, 100); } }); // Fix: // - onpostrender fires after DOM ready // - setTimeout ensures container exists // - jQuery finds #kata-edit-attributes // - Form HTML injected successfully // - User sees all fields!

Solution: Use onpostrender + setTimeout() để đảm bảo DOM ready.

✅ Fix 4: Better Shortcode Detection
