# 🚀 KATA Smart Chatbot - Quick Start

## ✅ Installation Complete!

KATA Smart Chatbot đã được tích hợp vào KATA SEO Manager plugin.

---

## 📋 Quick Setup (3 phút)

### 1️⃣ Activate Plugin
```
WordPress Admin → Plugins → KATA SEO Manager → Activate
```

### 2️⃣ Configure Chatbot
```
KATA SEO Manager → Smart Chatbot
```

**Cài đặt tối thiểu:**
- ✅ Bật "Kích hoạt Chatbot"
- ✅ Nhập Hotline: `1900 xxxx`
- ✅ Nhập Email: `support@timona.edu.vn`
- ✅ Màu chính: `#042277`

### 3️⃣ Test
```
Mở trang web → Chatbot hiện ở góc dưới phải → Click test!
```

3. Enter:
   - Provider: `OpenAI`
   - API Key: `sk-...`

## 🎯 Best Practices

### DO ✅
- Set delay 5-10s (không annoy user)
- Short welcome message
- 3-4 quick buttons max
- Follow-up leads < 5 phút

### DON'T ❌
- Auto-open ngay (0s)
- Long messages (> 3 dòng)
- Hỏi quá nhiều thông tin
- Spam messages

## 🐛 Troubleshooting

### Chatbot không hiện?
1. Clear cache (Ctrl+Shift+R)
2. Check Settings → "Kích hoạt" = ON
3. Check Console (F12) for errors

### Lead không lưu?
1. Check database tables created
2. Verify email format
3. Check error logs
