┌──────────────────────────────────────────────────────────────────────┐
│ 🎨 MÀU SẮC SCHEMA TAGS                                               │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  🟢 XANH LÁ (Active)                                                 │
│     → Schema đang được sử dụng trong bài viết                       │
│     → Đã implement thành công                                       │
│                                                                      │
│  🟠 CAM (Recommended)                                                │
│     → Gợi ý schema phù hợp cho bài viết                             │
│     → Click để copy shortcode                                       │
│     → Nên thêm vào để tối ưu SEO                                    │
│                                                                      │
│  🔵 XANH DƯƠNG (Suggested)                                           │
│     → Gợi ý cho bài chưa có schema                                  │
│     → Click để copy shortcode                                       │
│     → Ưu tiên cao                                                   │
│                                                                      │
│  ⚪ XÁM (Unused)                                                     │
│     → Schema chưa được sử dụng trong website                        │
│     → Cân nhắc triển khai nếu phù hợp                               │
│                                                                      │

┌──────────────────────────────────────────────────────────────────────┐
│ ⚡ TÍNH NĂNG NHANH                                                    │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  🎯 Copy Shortcode                                                  │
│  ────────────────                                                   │
│  1. Click vào schema tag màu CAM hoặc XANH DƯƠNG                    │
│  2. Shortcode tự động copy vào clipboard                            │
│  3. Thông báo hiện: "✅ Đã copy: [kata_article]"                    │
│  4. Paste vào editor để sử dụng                                     │
│                                                                      │
│  📝 Sửa bài nhanh                                                   │
│  ────────────────                                                   │
│  1. Click nút "Sửa" ở cột "Thao tác"                                │
│  2. Editor mở trực tiếp                                             │
│  3. Thêm schema vào nội dung                                        │
│  4. Lưu bài viết                                                    │
│                                                                      │
│  🔄 Làm mới dữ liệu                                                 │
│  ────────────────                                                   │
│  Click nút "Làm mới" ở góc trên phải                                │
│  → Page reload để cập nhật số liệu mới nhất                         │
│                                                                      │

│  • Ưu tiên 20 bài đầu tiên                                          │

│     • Update từng bài theo list                                     │

│     • So sánh % coverage qua thời gian                              │

┌──────────────────────────────────────────────────────────────────────┐
│ ⚠️  TROUBLESHOOTING                                                  │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  ❌ Vấn đề: Số liệu không chính xác                                 │
│  ✅ Giải pháp:                                                       │
│     1. Click nút "Làm mới"                                          │
│     2. Clear browser cache (Ctrl + Shift + R)                       │
│     3. Kiểm tra schema có đúng format [kata_*] không                │
│                                                                      │
│  ❌ Vấn đề: Schema không xuất hiện trong thống kê                   │
│  ✅ Giải pháp:                                                       │
│     1. Kiểm tra bài viết đã Publish chưa (Draft không count)        │
│     2. Xác nhận shortcode đúng format: [kata_article ...]           │
│     3. Schema phải nằm trong post_content (không phải custom field) │
│                                                                      │
│  ❌ Vấn đề: Search không hoạt động                                  │
│  ✅ Giải pháp:                                                       │
│     1. Refresh trang                                                │
│     2. Kiểm tra JavaScript console có lỗi không (F12)               │
│     3. Disable browser extensions (có thể conflict)                 │
│                                                                      │
│  ❌ Vấn đề: Copy shortcode không work                               │
│  ✅ Giải pháp:                                                       │
│     1. Browser phải hỗ trợ Clipboard API                            │
│     2. Thử browser khác (Chrome, Firefox recommended)               │
│     3. Workaround: Copy thủ công từ tooltip                         │
│                                                                      │
