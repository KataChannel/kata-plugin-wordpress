🎯 How It Works

Step-by-Step Guide

1

Tìm Shortcode trong Editor

Mở bài viết có KATA schema shortcode (text mode hoặc visual mode)

[kata_article title="Old Title" author="John"]
2

Double-Click vào Shortcode

Click 2 lần nhanh vào bất kỳ phần nào của shortcode

Tip: Click vào [kata_article hoặc bất kỳ attribute nào

3

Modal Tự Động Mở

Edit modal sẽ xuất hiện với form đã fill sẵn current values:

  • Title: Old Title (có thể edit)
  • Author: John (có thể edit)
  • Các fields khác (có thể add thêm)
4

Chỉnh Sửa Attributes

Modify bất kỳ field nào:

  • Change existing values
  • Add new attributes
  • Toggle checkboxes (show_schema, hide_content_*)
  • Edit long text in textareas
5

Update Schema

Click "Update Schema" button → Shortcode được cập nhật ngay!

Hoặc:

  • Delete Schema: Remove shortcode khỏi content
  • Cancel: Close modal không thay đổi

📊 Before vs After Comparison

❌ Before (Old Method)

  1. Find shortcode in editor
  2. Select entire shortcode text
  3. Delete shortcode
  4. Click "KATA SEO Manager" button
  5. Find schema template
  6. Fill all attributes again
  7. Insert new shortcode

⏱️ Time: ~60 seconds

❌ Risk: Lose data, syntax errors

✅ After (New Method)

  1. Find shortcode in editor
  2. Double-click on shortcode
  3. Edit attributes in modal
  4. Click "Update Schema"

⏱️ Time: ~10 seconds

✅ Safe: No data loss, validated form

⚡ 6x Faster + Zero Errors!

Save 50 seconds per edit × 10 edits/day = 8+ minutes saved daily

🔧 Technical Implementation

Core Functions

1. parseShortcode(text)

Extract schema type and attributes using regex:

function parseShortcode(shortcodeText) { return { type: 'article', // From [kata_article attributes: { title: "Old Title", // From title="..." author: "John", show_schema: "true" }, fullMatch: "[kata_article ...]" }; }

2. editExistingShortcode(node, text)

Open modal with parsed data:

editor.windowManager.open({ title: '✏️ Edit ARTICLE Schema', body: [...form fields...], buttons: ['Cancel', 'Update Schema', 'Delete Schema'] });

3. renderEditForm(parsed)

Render categorized form with smart input types:

Categories: - Basic Info: name, title, description - Content: ingredients, instructions - Meta: author, price, rating - Display: show_*, hide_content_* - Advanced: all others

4. updateShortcode(node, parsed)

Collect form values and update DOM:

var newShortcode = '[kata_' + type; // Collect all inputs newShortcode += ' attr="value"'; // Replace in editor editor.dom.setOuterHTML(node, newShortcode);
