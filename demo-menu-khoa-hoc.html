📚 Menu Khóa Học

Section với nền trắng và màu chữ phù hợp

🎯 Giới thiệu

Section menu-khoa-hoc được thiết kế với nền trắng (#ffffff) thay vì gradient như menu chính. Màu chữ được điều chỉnh phù hợp để dễ đọc trên nền trắng.

  • Background: White (#ffffff)
  • Text color: Primary (#042277)
  • Hover color: Secondary (#040B1E)
  • Icons: Gradient background
  • Buttons: Gradient style

📖 Cách Sử Dụng

1️⃣ Sử dụng class "menu-khoa-hoc"

<section class="menu-khoa-hoc">
    <h2 class="section-title">Danh Sách Khóa Học</h2>
    
    <div class="menu-grid">
        <div class="menu-item-card">
            <div class="menu-icon">📊</div>
            <div class="menu-item-title">Tên Khóa Học</div>
            <div class="menu-item-description">Mô tả khóa học</div>
            <a href="#" class="button">Xem Chi Tiết</a>
        </div>
    </div>
</section>

2️⃣ Hoặc sử dụng ID "menu-khoa-hoc"

<section id="menu-khoa-hoc">
    <h2>Khóa Học Phổ Biến</h2>
    <ul>
        <li><a href="#">Khóa học 1</a></li>
        <li><a href="#">Khóa học 2</a></li>
        <li><a href="#">Khóa học 3</a></li>
    </ul>
</section>

3️⃣ WordPress Shortcode (nếu có)

[section class="menu-khoa-hoc"]
    <h2>Danh Sách Khóa Học</h2>
    <!-- Nội dung khóa học -->
[/section]

🔌 Tích Hợp WordPress

CSS file menu-khoa-hoc.css đã được tự động enqueue trong functions.php: 

// File đã được thêm vào functions.php
wp_enqueue_style( 
    'timona-menu-khoa-hoc', 
    get_stylesheet_directory_uri() . '/assets/css/menu-khoa-hoc.css',
    array('timona-custom-fonts'),
    '1.0.2'
);

✅ Không cần cấu hình thêm, chỉ cần sử dụng class hoặc ID trong content!
