## 🎥 Recording Workflow

### Setup

1. **Close unnecessary apps** - Reduce CPU usage
2. **Clean desktop** - Hide personal files/bookmarks
3. **Set browser zoom to 100%** - Consistent UI size
4. **Disable notifications** - No interruptions
5. **Prepare demo content** - Have example text ready

### Recording Tips

**For Each Section:**

```bash
# Example workflow for Section 4 (MODE 2 Controls)
1. Read voice-over script out loud (practice)
2. Start screen recording
3. Perform actions slowly and deliberately
4. Pause 2-3 seconds between major actions
5. Stop recording
6. Review footage
7. Re-record if needed
```

**Recording Settings:**
- Resolution: 1920×1080
- Framerate: 30fps (or 60fps for smoother UI)
- Format: MP4 or MOV
- Quality: High (8-12 Mbps)

### Voice-Over Options

**Option A: Record simultaneously**
- Pros: Natural timing, authentic feel
- Cons: Hard to fix mistakes, may need re-recording

**Option B: Record separately**
- Pros: Better audio quality, easier to edit
- Cons: Requires sync in editing

**Recommended:** Record separately for professional results

## 🆘 Troubleshooting

### Common Issues

**Problem:** Recording is choppy  
**Solution:** Close other apps, reduce recording quality, or upgrade hardware

**Problem:** Audio has background noise  
**Solution:** Use noise reduction in Audacity, record in quiet room

**Problem:** Video file is too large  
**Solution:** Reduce bitrate to 8 Mbps, use more compression

**Problem:** Colors look washed out  
**Solution:** Adjust saturation in color grading, export with correct color profile

**Problem:** Text overlays are blurry  
**Solution:** Create text at 1080p resolution, avoid scaling up
