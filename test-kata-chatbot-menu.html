📋 Yêu cầu

⚠️ Quan trọng: Bạn PHẢI đăng nhập WordPress admin trước khi test!
  • ✅ Đã cài đặt plugin Kata Chatbot
  • ✅ Plugin đã được activate
  • ✅ Đã đăng nhập WordPress admin
  • ✅ Tài khoản có quyền manage_options (Administrator)

🔧 Hướng dẫn sử dụng

Bước 1: Đăng nhập WordPress Admin

Click vào link dưới để đăng nhập:

🔐 Đăng nhập WordPress Admin

Bước 2: Test các menu KATA Chatbot

Sau khi đăng nhập, click vào các link sau để test:

1. Smart Chatbot Settings (Cài đặt chatbot) http://localhost/timona/wp-admin/admin.php?page=kata-smart-chatbot 2. Chat Logs (Lịch sử chat) http://localhost/timona/wp-admin/admin.php?page=kata-chatbot-logs 3. Chatbot Leads (Khách hàng tiềm năng) http://localhost/timona/wp-admin/admin.php?page=kata-chatbot-leads

Bước 3: Hoặc dùng menu WordPress

Trong WordPress admin sidebar, tìm menu:

  • Kata Chatbot (menu chính)
  • → Smart Chatbot (submenu)
  • → Chat Logs (submenu)
  • → Leads (submenu)

❌ Nếu gặp lỗi 403 Forbidden

Nguyên nhân phổ biến:
  • Chưa đăng nhập: Bắt buộc phải login vào /wp-admin/ trước
  • Không có quyền: Tài khoản cần role Administrator hoặc có capability manage_options
  • Plugin chưa activate: Kiểm tra trong Plugins → Installed Plugins
  • Cache: Clear browser cache và reload trang (Ctrl + Shift + R)
💡 Mẹo debug:
  1. Mở Developer Tools (F12)
  2. Vào tab Network
  3. Click vào URL có lỗi 403
  4. Kiểm tra Response Headers để xem lý do

✅ Kết quả mong đợi

Nếu thành công, bạn sẽ thấy:
  • ✓ Trang Smart Chatbot Settings với 6 tabs: General, Triggers, UI, Messages, Contact, AI
  • ✓ Trang Chat Logs hiển thị danh sách tin nhắn chatbot
  • ✓ Trang Leads hiển thị danh sách khách hàng tiềm năng
  • ✓ Menu "Kata Chatbot" xuất hiện ở sidebar admin
