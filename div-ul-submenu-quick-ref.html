🔄 DIV = UL Submenu

Quick Reference v1.0.3

✅ Updated!

DIV.sub-menu giờ hoạt động giống Y HỆT như UL.sub-menu

UL.sub-menu

<ul class="sub-menu"> <li><a>Item</a></li> </ul>
Standard

DIV.sub-menu

<div class="sub-menu"> <a>Item</a> </div>
Updated!

🎨 Properties

Property Value
Background linear-gradient(#042277, #040B1E)
Text Color #ffffff (white)
Border Top 3px solid #ffffff
Hover BG rgba(255, 255, 255, 0.1)
Hover Color #ffffff (stays white)

📝 CSS Applied

/* Both UL and DIV */ div.sub-menu, ul.sub-menu, div.nav-dropdown, ul.nav-dropdown { background: linear-gradient(to bottom, #042277, #040B1E) !important; border-top: 3px solid #ffffff; } div.sub-menu a, ul.sub-menu li a { color: #ffffff !important; } div.sub-menu a:hover, ul.sub-menu li a:hover { color: #ffffff !important; background: rgba(255, 255, 255, 0.1) !important; }
