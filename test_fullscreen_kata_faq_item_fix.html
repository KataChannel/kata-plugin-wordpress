🐛 Bug 1: Fullscreen Modal Footer Overflow

❌ Vấn đề

Khi mở edit modal fullscreen (width: window.innerWidth, height: window.innerHeight), phần footer chứa buttons (Update, Cancel, Delete) bị tràn ra ngoài màn hình, user không thấy được buttons.

// ❌ OLD CODE - Fixed positioning caused footer overflow width: window.innerWidth, height: window.innerHeight, resizable: false, maximizable: false, html: '<div style="position:fixed;top:0;left:0;right:0;bottom:0;...">'

Root cause: Layout position: fixed với top:0;left:0;right:0;bottom:0 chiếm toàn bộ viewport, không để chỗ cho TinyMCE footer.

✅ Giải pháp

Thay đổi từ fixed fullscreen sang responsive modal với max-height tính toán:

// ✅ NEW CODE - Responsive with proper spacing width: Math.min(window.innerWidth - 40, 1600), height: Math.min(window.innerHeight - 40, 1000), resizable: true, maximizable: true, html: '<div style="display:flex;flex-direction:column;height:100%;max-height:calc(100vh - 200px);...">'
  • 1. Modal size: window.innerWidth - 40 (margin 20px mỗi bên)
  • 2. Max height: calc(100vh - 200px) (để chỗ cho header + footer)
  • 3. Resizable: true (user có thể điều chỉnh)
  • 4. Layout: Flexbox với min-height: 0 để scroll hoạt động

❌ Before (Footer tràn)

• Modal: 100vw × 100vh
• Layout: position: fixed
• Footer: Bị đẩy ra ngoài màn hình
• Buttons: Không visible
• Scroll: Không hoạt động đúng

✅ After (Footer visible)

• Modal: (100vw - 40px) × (100vh - 40px)
• Layout: display: flex, max-height
• Footer: Luôn visible
• Buttons: Update, Cancel, Delete
• Scroll: Smooth trong content area

🐛 Bug 2: kata_faq_item Detection Không Hoạt Động

❌ Vấn đề

Double-click vào shortcode [kata_faq_item question="..." answer="..."] không mở edit modal. Regex cũ không match được shortcode có attributes dài hoặc multi-line.

// ❌ OLD REGEX - Không match multi-line var shortcodeMatch = content.match(/\[kata_\w+[^\]]*\]/); // ❌ PROBLEMS: // 1. \w+ không match underscore (kata_faq_item ❌) // 2. [^\]]* không match newlines trong attributes // 3. Không get parent context cho better matching

Example không hoạt động:

[kata_faq_item question="KATA SEO Manager có miễn phí không?" answer="KATA SEO Manager hoàn toàn miễn phí..."]

✅ Giải pháp

Update regex + add parent node context để match đúng tất cả shortcodes:

// ✅ NEW REGEX - Match multi-line + underscore var shortcodeMatch = content.match(/\[kata_[\w_]+(?:\s+[\s\S]*?)?\]/); // ✅ IMPROVEMENTS: // 1. [\w_]+ matches kata_faq_item ✅ // 2. (?:\s+[\s\S]*?)? matches multi-line attributes ✅ // 3. Get parent node content for better context ✅ // 4. Enhanced logging with nodeType + nodeName ✅
  • 1. [\w_]+ - Match word chars + underscore (kata_faq_item ✅)
  • 2. [\s\S]*? - Match any char including newlines (lazy)
  • 3. Parent context - Get parent node content for better matching
  • 4. Enhanced logging - Debug info: nodeType, nodeName, matched length

❌ Before (Không match)

Regex: /\[kata_\w+[^\]]*\]/

Không match:
• [kata_faq_item ...] ❌
• Multi-line attributes ❌
• Long attributes ❌

Context: Chỉ node content

✅ After (Match đúng)

Regex: /\[kata_[\w_]+(?:\s+[\s\S]*?)?\]/

Match đúng:
• [kata_faq_item ...] ✅
• Multi-line attributes ✅
• Long attributes ✅

Context: Node + parent content
