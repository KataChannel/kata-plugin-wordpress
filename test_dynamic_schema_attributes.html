⚡ Dynamic Schema Attributes

Tùy chỉnh thuộc tính Schema cho Dynamic Schema

6 Schema Attributes
3 Content Attributes

📋 MODE 1: Schema Attributes (JSON-LD Control)

6 Schema Attributes Available:

hide_json_code Ẩn JSON code trong schema
hide_validate Tắt validation
hide_pretty_print Tắt pretty print
hide_minify Tắt minify
hide_auto_context Tắt auto @context
hide_escape_quotes Tắt escape quotes

💡 Use Case: Disable Validation

Tắt JSON validation khi bạn chắc chắn JSON đúng syntax:

[kata_dynamic 
    json_code='{"@context":"https://schema.org","@type":"WebSite","name":"example.com"}' 
    hide_validate="true" 
    show_schema="true"]

💡 Use Case: Force Minify OFF

Muốn JSON readable ngay cả khi có minify="true":

[kata_dynamic 
    json_code='{"@context":"https://schema.org","@type":"Person","name":"John"}' 
    minify="true" 
    hide_minify="true" 
    show_schema="true"]

💡 Use Case: Disable Auto Context

Không muốn tự động thêm @context (JSON đã có sẵn):

[kata_dynamic 
    json_code='{"@context":"https://schema.org","@type":"Organization","name":"KATA"}' 
    auto_context="true" 
    hide_auto_context="true" 
    show_schema="true"]

🎨 MODE 2: Content Attributes (Frontend Display)

3 Content Attributes Available:

hide_content_info Ẩn schema info box
hide_content_raw Ẩn raw JSON display
hide_content_formatted Ẩn property table

💡 Use Case: Show Only Info Box

Hiển thị chỉ schema info, ẩn raw JSON và table:

[kata_dynamic 
    json_code='{"@context":"https://schema.org","@type":"Product","name":"iPhone 15"}' 
    schema_name="iPhone 15 Pro" 
    description="Flagship smartphone" 
    show_frontend="true" 
    show_info="true" 
    hide_content_raw="true" 
    hide_content_formatted="true"]

💡 Use Case: Show Only Raw JSON

Chỉ hiển thị raw JSON code, ẩn info box và table:

[kata_dynamic 
    json_code='{"@context":"https://schema.org","@type":"Event","name":"WordPress Meetup"}' 
    show_frontend="true" 
    show_raw="true" 
    hide_content_info="true" 
    hide_content_formatted="true"]

💡 Use Case: Show Only Property Table

Chỉ table với properties, không cần info hay raw JSON:

[kata_dynamic 
    json_code='{"@context":"https://schema.org","@type":"Course","name":"WordPress Development"}' 
    show_frontend="true" 
    show_content_formatted="true" 
    hide_content_info="true" 
    hide_content_raw="true"]

🔄 MODE 1 + 2: Combined Attribute Control

💡 Production Optimized

Schema only, no frontend, minified, no validation overhead:

[kata_dynamic 
    json_code='{"@context":"https://schema.org","@type":"WebSite","name":"example.com","url":"https://example.com"}' 
    minify="true" 
    hide_validate="true" 
    show_schema="true" 
    show_frontend="false" 
    hide_content_info="true" 
    hide_content_raw="true" 
    hide_content_formatted="true"]

💡 Development Full Debug

Show everything cho debugging và testing:

[kata_dynamic 
    json_code='{"@context":"https://schema.org","@type":"Organization","name":"KATA Digital","url":"https://katadigital.com"}' 
    schema_name="KATA Digital Agency" 
    description="Digital Marketing Agency" 
    validate="true" 
    pretty_print="true" 
    show_schema="true" 
    show_frontend="true" 
    show_info="true" 
    show_raw="true" 
    show_content_formatted="true"]

💡 Custom Selective Display

Pick and choose specific components:

[kata_dynamic 
    json_code='{"@context":"https://schema.org","@type":"Person","name":"Nguyễn Văn A","jobTitle":"SEO Specialist"}' 
    schema_name="Nguyễn Văn A" 
    show_schema="true" 
    show_frontend="true" 
    show_info="true" 
    show_raw="true" 
    hide_content_formatted="true" 
    pretty_print="true" 
    hide_minify="true"]

🎨 TinyMCE Integration

✅ Dynamic Schema Attributes trong TinyMCE Modal

  • Mở TinyMCE Editor → Click "KATA SEO Manager" button
  • Chọn "⚡ Dynamic Schema (Custom JSON-LD)" template
  • Scroll xuống phần "⚙️ Tùy chỉnh thuộc tính Schema"
  • Thấy 2 sections:
    • 📋 Schema Fields: 6 checkboxes (json_code, validate, pretty_print, minify, auto_context, escape_quotes)
    • 🎨 Content Display: 3 checkboxes (info, raw, formatted)
  • Check/uncheck để add hide_* attributes vào shortcode
  • Click "Insert Shortcode" → Code tự động có attributes!

🔧 How It Works

JavaScript Config:

// tinymce-plugin.js line 1209-1212
dynamic: {
    schema: ['json_code', 'validate', 'pretty_print', 'minify', 'auto_context', 'escape_quotes'],
    content: ['info', 'raw', 'formatted']
}

💡 Best Practices

✅ Recommended Configurations:

  • Production (Live Site):
    • minify="true" → Compact JSON
    • hide_validate="true" → Skip validation overhead
    • show_frontend="false" → No visual display
    • hide_content_*="true" → All content hidden
  • Development (Testing):
    • validate="true" → Catch errors early
    • pretty_print="true" → Readable JSON
    • show_frontend="true" → Visual debugging
    • All content visible (no hide_* attributes)
  • Documentation (Demos):
    • show_info="true" → Schema overview
    • show_raw="true" → Code examples
    • hide_content_formatted="true" → Less clutter
    • pretty_print="true" → Easy to read
