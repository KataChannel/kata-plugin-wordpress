🌐 Test 1: WebSite Schema (Minimal)

Mục đích: Test basic WebSite schema với minimal attributes

Tính năng test: JSON validation, auto @context, schema output

JSON-LD WebSite type
Auto @context
Schema only (no frontend)
Validation enabled

📋 Shortcode:

[kata_dynamic 
    json_code='{"@context":"https://schema.org","@type":"WebSite","name":"example.com","url":"https://www.example.com/"}' 
    show_schema="true" 
    show_frontend="false" 
    validate="true"]

✅ Expected JSON-LD Output:

{ "@context": "https://schema.org", "@type": "WebSite", "name": "example.com", "url": "https://www.example.com/" }

🔍 Validation Checklist:

  • Có <script type="application/ld+json"> tag
  • JSON syntax hợp lệ
  • @context = "https://schema.org"
  • @type = "WebSite"
  • Không có frontend HTML display

Tính năng test: auto_context (không cần manual @context)

Person type
Auto @context
Property table display
Frontend enabled

📋 Shortcode:

[kata_dynamic 
    json_code='{"@type":"Person","name":"Nguyễn Văn A","jobTitle":"SEO Specialist","email":"nguyenvana@example.com","url":"https://example.com/author/nguyen-van-a","image":"https://example.com/avatar.jpg","sameAs":["https://facebook.com/nguyenvana","https://linkedin.com/in/nguyenvana","https://twitter.com/nguyenvana"]}'

Tính năng test: pretty_print="true" vs minify="true"

📋 Shortcode B: Minified

[kata_dynamic 
    json_code='{"@context":"https://schema.org","@type":"Recipe","name":"Phở Bò","recipeIngredient":["Xương bò","Thịt bò","Bánh phở"],"recipeInstructions":[{"@type":"HowToStep","text":"Luộc xương"},{"@type":"HowToStep","text":"Thái thịt"}]}' 
    minify="true"

{"@context":"https://schema.org","@type":"Recipe","name":"Phở Bò","recipeIngredient":["Xương bò","Thịt bò","Bánh phở"],"recipeInstructions":[{"@type":"HowToStep","text":"Luộc xương"},{"@type":"HowToStep","text":"Thái thịt"}]}

🔍 Validation Checklist:

  • Pretty print: Có indentation và line breaks
  • Minified: Một dòng, không có whitespace

Mục đích: Test schema với multiple @type values

Tính năng test: Array @type support, schema.org multiple types

📋 Shortcode:

[kata_dynamic 
    json_code='{"@context":"https://schema.org","@type":["BlogPosting","NewsArticle"],"headline":"Breaking News: WordPress 6.5 Released","author":{"@type":"Person","name":"John Doe"},"datePublished":"2025-10-09","articleBody":"WordPress 6.5 brings major improvements..."}' 
    schema_name="Blog Post + News Article" 
    description="Schema với multiple types" 
    show_schema="true" 
    show_frontend="true" 
    show_info="true" 
    validate="true"]

✅ Expected Schema:

Schema.org cho phép combine multiple types. Ví dụ:

  • BlogPosting + NewsArticle (tin tức blog)
  • LocalBusiness + Restaurant (nhà hàng local)
  • Product + SoftwareApplication (software product)

🔍 Validation Checklist:

  • @type là array của strings
  • Schema info box hiển thị types correctly
  • Google Rich Results Test accepts it
  • Property table shows all properties

💡 Best Practices & Tips

✅ DO's:

  • ✅ Always test JSON với validator trước khi deploy
  • ✅ Use pretty_print="true" during development
  • ✅ Use minify="true" in production để giảm size
  • ✅ Enable validate="true" để catch errors sớm
  • ✅ Use auto_context="true" khi copy từ external sources
  • ✅ Set error_display="false" in production
  • ✅ Test với Google Rich Results Tool trước khi publish

❌ DON'Ts:

  • ❌ Không dùng single quotes cho JSON (phải dùng double quotes)
  • ❌ Không quên escape special characters trong values
  • ❌ Không output duplicate schemas (check existing ones)
  • ❌ Không enable frontend display nếu không cần (performance)
  • ❌ Không hardcode dates - use dynamic values khi possible

🎯 Common Use Cases:

  1. Import from Google Tool: Copy JSON từ Structured Data Tool → paste vào json_code
  2. Custom Schema Types: Test schema types chưa có trong plugin (SoftwareApplication, MusicEvent, etc.)
  3. Prototype New Features: Test schema mới trước khi code permanent render function
  4. Override Defaults: Override plugin's default schemas cho specific pages
  5. Multiple @types: Combine types (LocalBusiness + Restaurant)
  6. Testing & Debug: Use show_frontend="true" để visualize schema structure
