💻 Basic Usage

Option 1: Sử dụng class

<section class="menu-khoa-hoc"> <h2>Danh Sách Khóa Học</h2> <!-- Content --> </section>

Option 2: Sử dụng ID

<div id="menu-khoa-hoc"> <h2>Khóa Học Phổ Biến</h2> <!-- Content --> </div>

📐 Grid Layout Example

<section class="menu-khoa-hoc"> <h2>Khóa Học Marketing</h2> <div class="menu-grid"> <div class="menu-item-card"> <div class="menu-icon">📊</div> <div class="menu-item-title">SEO Cơ Bản</div> <div class="menu-item-description"> Học tối ưu hóa website </div> <a href="#" class="button">Xem Chi Tiết</a> </div> <!-- More cards... --> </div> </section>

🎯 Available CSS Classes

Class Purpose
.menu-khoa-hoc Container chính (hoặc dùng #menu-khoa-hoc)
.menu-grid Grid layout responsive
.menu-item-card Card cho từng khóa học
.menu-icon Icon với gradient background
.menu-item-title Tiêu đề khóa học
.menu-item-description Mô tả khóa học
.button Button với gradient
.button-outline Outline button style

✨ Features

  • Nền trắng - Background #ffffff thay vì gradient
  • Text màu primary - Color #042277 dễ đọc
  • Hover effect - Chuyển màu #040B1E smooth
  • Responsive grid - Auto 1-4 columns based on screen
  • Gradient icons - Icons với background đẹp mắt
  • Gradient buttons - Buttons nổi bật
  • Card hover - Border + shadow khi hover
  • Mobile friendly - Tối ưu cho mọi thiết bị

🔌 WordPress Integration

CSS đã được auto-enqueued trong functions.php:

wp_enqueue_style( 'timona-menu-khoa-hoc', get_stylesheet_directory_uri() . '/assets/css/menu-khoa-hoc.css', array('timona-custom-fonts'), '1.0.2' );
