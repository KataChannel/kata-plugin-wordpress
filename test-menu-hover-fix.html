✅ Kết quả mong đợi khi hover:

  • Text color: WHITE (#ffffff)
  • Opacity: 0.85 (giảm nhẹ)
  • Background: rgba(255, 255, 255, 0.1) (highlight nhẹ)
  • Transform: translateY(-2px) (nhảy nhẹ lên)

🔧 CSS Solution

/* Force white text on hover - Ultimate override */ html body .header a:hover { color: #ffffff !important; opacity: 0.85; } /* High specificity selector */ #wrapper .header-main .nav > li > a:hover { color: #ffffff !important; } /* All link states */ .header a:link, .header a:visited, .header a:hover, .header a:active { color: #ffffff !important; }
