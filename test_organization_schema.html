🎯 Features Summary

Feature Attribute Description
Core Info name Organization name (required)
legal_name Legal registered name
url Official website URL
logo Logo image URL
image Additional images (comma separated)
description Organization description
slogan Company slogan/tagline
Contact phone Phone number
email Email address
address Physical address
Details founding_date Date established (YYYY-MM-DD)
founder Founder name(s)
number_of_employees Employee count
tax_id Tax identification number
duns DUNS number
Additional area_served Geographic coverage (comma separated)
contact_point Contact info: Type|Phone|Email
same_as Social profiles (comma separated URLs)
award Awards (comma separated)
Display show_schema true/false - Show JSON-LD schema
show_frontend true/false - Show HTML output
