🐛 BUG: Schema Markup không render trong <head>

🔍 ROOT CAUSE:
   - Functions store_shortcode_schema() & get_shortcode_schemas()
   - Were PRIVATE → should be PUBLIC
   - Result: Schemas collected but never output

✅ FIX APPLIED:
   File: kata-seo-manager.php
   Lines: 1024, 1041
   Change: private → public
   
   Before:
   private function store_shortcode_schema() {...}
   private function get_shortcode_schemas() {...}
   
   After:
   public function store_shortcode_schema() {...}
   public function get_shortcode_schemas() {...}

💡 HOW IT WORKS NOW:

   1. User adds shortcode:
      [kata_article title="..." show_schema="true"]
   
   2. Shortcode processes:
      render_article() executes
      
   3. Schema stored:
      $this->store_shortcode_schema($schema, 'Article')
   
   4. wp_head fires:
      output_schema_markup() runs
      
   5. Schemas output:
      <script type="application/ld+json">
      { ... schema ... }
      </script>
