# ✏️ EDIT SHORTCODE - QUICK REFERENCE

## 🚀 How to Edit Shortcode

### Method: Double-Click
```
1. Tìm shortcode trong editor
2. Double-click vào bất kỳ chỗ nào của shortcode
3. Modal tự động mở với data đã fill
4. Edit attributes
5. Click "Update Schema"
```

**Time**: 10 seconds (vs 60 seconds old method)

## 💡 Common Edits

### Fix Typo
```
[kata_article title="SEO Tpis"]
↓ Double-click → Edit
[kata_article title="SEO Tips"]
```

### Toggle Display
```
[kata_recipe show_schema="true"]
↓ Double-click → Check "show_frontend"
[kata_recipe show_schema="true" show_frontend="true"]
```

### Add Attributes
```
[kata_product name="iPhone"]
↓ Double-click → Add price, brand
[kata_product name="iPhone" price="29990000" brand="Apple"]
```

### Update Values
```
[kata_dynamic json_code='{"@type":"WebSite"}']
↓ Double-click → Edit JSON
[kata_dynamic json_code='{"@type":"WebSite","name":"example"}']
```

### Delete Schema
```
[kata_event name="Old Event"]
↓ Double-click → Click "Delete" → Confirm
(removed)
```

## 🚨 Important Notes

### ✅ Works In:
- Text Editor (WordPress default)
- Visual Editor (TinyMCE)
- Classic Editor plugin

### ⚠️ Gutenberg:
Use "Edit as HTML" mode first, then double-click

### 📝 Nested Shortcodes:
```
[kata_faq]
  [kata_faq_item ...] ← Can edit individually
  [kata_faq_item ...] ← Can edit individually
[/kata_faq]
```

## 🎓 Examples

### Example 1: Article
```php
// Before
[kata_article title="SEO Tips" author="John"]

// Edit: title="SEO Tips 2024", author="Jane", category="Marketing"

// After
[kata_article title="SEO Tips 2024" author="Jane" category="Marketing"]
```

### Example 2: Recipe
```php
// Before
[kata_recipe name="Pho Bo" prep_time="30M"]

// Edit: name="Pho Bo Ha Noi", prep_time="45M", cook_time="2H", servings="4"

// After
[kata_recipe name="Pho Bo Ha Noi" prep_time="45M" cook_time="2H" servings="4"]
```

### Example 3: Dynamic
```php
// Before
[kata_dynamic json_code='{"@type":"WebSite"}' validate="true"]

// Edit: json_code updated, show_frontend="true", show_info="true"

// After
[kata_dynamic json_code='{"@type":"WebSite","name":"example.com"}' validate="true" show_frontend="true" show_info="true"]
```
